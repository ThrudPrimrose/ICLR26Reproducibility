"""Optimized implementation of the TSVC_2 kernel ``s1232``.

The reference NumPy implementation (see ``/shared/tasks/tsvc_2_s1232/tsvc_2_s1232_numpy.py``)
uses explicit Python loops over the two dimensions.  For the Python arm of the benchmark the
baseline is a ``numba.njit`` compiled version of that loop, which is still much slower than a
fully vectorised NumPy solution.

This implementation follows the *in‑place* ABI expected by the harness: the output array ``aa``
is provided by the caller and must be filled where required, leaving the rest of its content
unchanged.  The kernel computes

    aa[i, j] = bb[i, j] + cc[i, j]   for i >= j * VLEN

for all ``0 <= i, j < LEN_2D``.

The algorithm builds a boolean mask of shape ``(LEN_2D, LEN_2D)`` where the condition holds and
uses ``numpy.add`` with the ``where`` keyword to perform the addition only on the masked entries.
Using ``where=mask`` avoids creating a temporary result for the whole matrix – the addition is
performed element‑wise directly into ``aa`` where the mask is true, and ``aa`` is left untouched
elsewhere.

The mask is constructed with broadcasting; the cost of building the mask is ``O(N^2)`` boolean
operations, which is negligible compared to the memory traffic of the addition itself.  The
implementation does not retain any per‑size cache – the harness may invoke the kernel with sizes
that were not seen before, and recomputing the mask each call ensures correctness without any
stateful caching.
"""

from __future__ import annotations

import numpy as np


def s1232(
    aa: np.ndarray,
    bb: np.ndarray,
    cc: np.ndarray,
    LEN_2D: int,
    VLEN: int,
) -> None:
    """In‑place kernel for TSVC_2 ``s1232``.

    Parameters
    ----------
    aa, bb, cc:
        ``LEN_2D``×``LEN_2D`` arrays of the same dtype. ``aa`` is the output buffer.
    LEN_2D:
        Size of each dimension.
    VLEN:
        Vector length factor used in the lower‑bound condition.
    """
    # Build a mask where the condition i >= j * VLEN holds.
    # ``i`` varies over rows, ``j`` over columns.
    # Use int64 to avoid overflow in the multiplication.
    i = np.arange(LEN_2D, dtype=np.int64)[:, None]
    j = np.arange(LEN_2D, dtype=np.int64)[None, :]
    mask = i >= j * VLEN
    # Perform the addition only where the mask is True, writing directly into ``aa``.
    # ``where`` leaves ``aa`` unchanged where ``mask`` is False.
    np.add(bb, cc, out=aa, where=mask)
    # No return needed for the in‑place ABI.
    return None
